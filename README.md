# 📜 Las Islas de Vin 

Bienvenido al repositorio oficial de la campaña **"Las Islas de Vin"**.  
Este vault de Obsidian contiene toda la información del mundo, los personajes, las reglas personalizadas y los secretos del director de juego.

---

## 🗂️ Estructura de Carpetas (¿Dónde está cada cosa?)
Para que te orientes rápidamente, aquí tienes el árbol de directorios y la explicación de cada carpeta pertinente:


├── Campaña/ # 📖 Notas generales de la campaña  
│  
│├── Las islas de Vin/ # 🏝️ El corazón del setting. ¡Aquí está casi todo!  
││├── 00 Clases personalizadas/ # ⚔️ Clases, subclases y talentos homebrew  
││├── 01 Objetos/ # 🗡️ Objetos mágicos, equipo y artefactos únicos  
││├── 02 Jugadores/ # 🧙 Fichas de PJs, trasfondos y resúmenes de los jugadores  
││├── 03 Experiencia/ # 📈 Seguimiento de XP, hitos de nivel y progresión  
││├── Criaturas/ # 🐉 Bestiario (criaturas homebrew y modificadas)  
││├── Lore/ # 🌍 Historia, geografía, religión y mitología de las islas  
││└── NPCs/ # 🗣️ Personajes no jugadores (motivaciones, secretos, localización)  
│  
├── Sesiones - NO VER/ # 🚨 ¡ZONA PROHIBIDA PARA JUGADORES!  
│ 
└── Plantillas/ # 🧩 Plantillas reutilizables (para NPCs, objetos, notas de sesión, etc.)
